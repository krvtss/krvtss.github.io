Unity C# 3D UI AI & Context Steering Audio Architecture

Systems Engineered

  • 3D World-Space Merge Inventory & Auto-Tooltips: Created a tactile inventory rendered in 3D world space with responsive drag-and-drop UI interaction. Players merge identical items to upgrade tiers, backed by a dynamic tooltip system that automatically parses item types, resolves matching UI icons, and displays live stats.
  • Modular Equipment & Curve-Based Stat Scaling: Architected an inheritance/composition item base supporting weapons, armor, grappling hooks, and deployables. Invoking a sound ID automatically selects randomized clip variations, applies subtle pitch modulation, and exposes separate API calls for 2D UI audio vs. 3D spatialized audio (panning in headphones relative to player distance).
  • Enemy AI (Context Steering & Ballistic Trajectories):
    • Implemented Context Steering across flying and ground enemies for smooth obstacle avoidance around 2.5D grid blocks.
    • Crab AI: Calculates ballistic jump trajectories when approaching gaps, ledges, or elevated player positions to leap across terrain and land melee hits.
    • Snake AI: Glides from screen edge to edge, dynamically curving its skeletal mesh spine along its movement vector.
